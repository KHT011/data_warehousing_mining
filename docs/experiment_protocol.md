# Experiment protocol

Regression target is an observed rating, not top-N recommendation. Select up to one million events using deterministic DuckDB hash(event ID || seed) before splitting. Record actual sample size, source run IDs and code hash. Sort by epoch and event ID; timestamp boundaries approximate 70/15/15 and keep ties together. Empty splits fail explicitly.

Training-row user/movie means and counts exclude the row's own target. Singleton fallbacks also exclude the target from the training global mean. This is a leave-one-out approximation and can use later training-period labels; it is not strict earlier-event forecasting. Validation/test rows use training aggregates only. Encoded MovieLens genres are retrospective catalog descriptors. IDs are lookup keys, never continuous model inputs. Runtime/language are currently excluded from the primary experiment as enrichment is not required. Current TMDB popularity/votes and all tags are excluded.

Fit median imputation and missingness indicators only on training data. Baseline A is training global mean; B uses alternating regularized user/movie biases with validation selection over penalties [5,10,25]. Unknown keys use zero bias. XGBoost selects depth 4 or 6 using validation, with 150 histogram trees, learning rate .05, CPU threads 2 and seed 42. Test labels never select parameters. The commands are manual experiments; rerunning test evaluation is not a fresh final holdout. Freeze the chosen setup before the final report.

Save unclipped and clipped [0.5,5] RMSE/MAE, predictions, test support, warm/cold metrics, model and preprocessing. Paired user-block bootstrap reports 200 resamples of MSE difference, preserving event dependence within user; it is not a universal significance claim. Feature importance is descriptive, not causal. Controlled scaling uses 100 trees/depth 4 on deterministic 100k/500k/1M pre-split samples and reports preparation separately from fit throughput.

Clustering uses all rating-active warehouse users. Descriptors: log rating count, mean/std, activity span and weighted genre proportions, summing to one. Standardize, try K=[2,3,4,5,6,8], MiniBatchKMeans n_init=3 with seeds 42/43. Save inertia, sizes, runtime, adjusted Rand stability and silhouette on a fixed sample of at most 5,000 users. Compare ordinary KMeans on this sample. Automatically select highest sampled silhouette as a preliminary result, then inspect profiles/stability/support for interpretation. No cluster names or conclusions are predeclared.

OLAP: preserve SQL/parameters, result count, EXPLAIN and EXPLAIN ANALYZE, one warm-up and five repetitions; report median/min/max/std and raw repetition times. Compare sorted fact scan to movie/month preaggregation, checking answer equivalence within floating tolerance. Both are warm-cache runs; no cold-cache claim. Record hardware exposed to the container, threads, versions, fact count and aggregate construction time.

Original tag-topic H1 is not tested by genre clustering. Original deep-learning H3 is not fully tested by XGBoost versus mean/bias; revise hypotheses or add those experiments. MovieLens recorded ratings are not verified viewing events; behavioral groups are not population demographics. The 20M release meets the assignment's 5M+ minimum while exceeding its suggested 5–10M scale.
